# Docker Demo: Ancillary Files

Welcome to the **Docker Demo** exhibit! This tutorial demonstrates the new **ancillary files** feature.

## What are Ancillary Files?

Ancillary files are step-specific resources like:
- Dockerfiles
- docker-compose.yml files
- Setup scripts
- Configuration files

These files live alongside the exhibit and are referenced in the YAML configuration.

## What You'll Learn

In this demo, you'll:
1. Learn about ancillary files (this step)
2. Build a Docker image using an ancillary Dockerfile
3. Run a container using an ancillary docker-compose file
