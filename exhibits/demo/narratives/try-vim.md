# Try Vim

Now let's test vim in the browser terminal.

Run this command to create and edit a file:

```bash
vim hello.txt
```

Once in vim:
1. Press `i` to enter insert mode
2. Type some text
3. Press `Esc` to exit insert mode
4. Type `:wq` and press Enter to save and quit

Then verify your file was created:

```bash
cat hello.txt
```

If you see your text, you've completed this step!
