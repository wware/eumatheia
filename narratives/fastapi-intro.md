# Building a FastAPI CRUD Application

Welcome! In this tutorial, you'll explore a complete CRUD (Create, Read, Update, Delete) application using FastAPI and SQLite.

## What You'll See

A fully-functional **Items Manager** with:
- **Auto-incrementing IDs** - Database-managed sequential numbering
- **Random name generation** - 10-character lowercase names when you don't provide one
- **RESTful API** - Clean HTTP endpoints for all operations
- **Interactive web UI** - Single-page app with real-time updates

## The Technology Stack

The app uses:
- **Pydantic models** for request/response validation
- **SQLite** for lightweight data persistence
- **FastAPI** for the REST API with auto-generated docs
- **HTML/JavaScript** frontend served from the root path
